# Studia

Public pages for the Studia TikTok app, served by GitHub Pages at https://quentinfelice.github.io/tiktok/

- `terms.html`, `privacy.html`: legal pages required by TikTok for Developers
- `callback.html`: OAuth redirect page (shows the one-time code, sends nothing)
- `media/`: slideshow images TikTok pulls for draft uploads (verified URL prefix)

Source of truth: `departments/tiktok/site/` in the studio repository.
